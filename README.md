# Hi, I'm Alonso!  
> ### *Energy Engineer | Aspiring Data Engineer | SQL & Python Enthusiast*

I'm an Energy Engineer passionate about turning raw data into reliable insights. I genuinely enjoy transforming complex datasets into clean, structured solutions.

Along my journey, I've worked closely with RDBMS like Oracle SQL Developer, SSMS, and MySQL. While I have built visualizations in Power BI and Looker (GCP), I realized that designing dashboards isn't where my passion lies. Because of this, I am actively steering my career toward **Data Engineering**, focusing on the under-the-hood processes that make data reliable.

My absolute favorite tools for transforming and analyzing data are **SQL** and **Python**, although I'm always eager to learn new tools and methodologies as my career grows. This repository is where I showcase my work with database modeling, ETL processes, and data manipulation.
